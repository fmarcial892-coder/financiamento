# Financiamento BV — site estático

Site estático de orientação independente da **BP Gestão e Recuperação de Ativos Ltda.**, com identificação empresarial e CTAs para o WhatsApp informado pela empresa.

## Publicação atual na Render

O serviço Render `financiamento` está ligado ao repositório `fmarcial892-coder/financiamento`, branch `main`, e publica a raiz (`./`). A página canônica é `index.html`.

A pasta `financiamentobv/` é mantida como cópia legada sincronizada para compatibilidade com versões anteriores.

## Segurança e transparência

- A página informa que não é o site oficial do banco BV.
- Exibe CNPJ, endereço, contatos empresariais, atividades e custos.
- Não coleta senha, token, CPF ou dados bancários.
- Cada serviço abre uma mensagem contextual no WhatsApp.
- Privacidade e termos estão disponíveis na própria página.

A conformidade com Google Ads depende também da verificação do anunciante, licenças/isenções, operação real e revisão da conta. O CNPJ não garante aprovação ou ausência de suspensão.
